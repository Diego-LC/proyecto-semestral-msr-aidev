# Proyecto Semestral: Recomendación MSR

La recomendación para un grupo de `2 personas` es trabajar con el desafío de `MSR 2026` usando el dataset `AIDev`, porque permite un proyecto más acotado, empírico y defendible que la opción de `VISSOFT 2026`.

## Propuesta Seleccionada

`¿Qué revela la intervención humana sobre la autonomía de los agentes de IA como contribuidores de software?`

Razones:

- tiene una pregunta clara y útil;
- combina análisis cuantitativo y revisión de casos;
- se puede abordar bien con dos personas;
- evita depender de construir una herramienta visual compleja.
